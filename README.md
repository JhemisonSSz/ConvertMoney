# 💸 ConvertMoney

O ConvertMoney é uma aplicação web simples e intuitiva desenvolvida para realizar a conversão de moedas em tempo real. 
O objetivo do projeto é oferecer uma interface amigável para que o usuário possa converter valores entre diferentes moedas de forma rápida e precisa.

---

## 🚀 Funcionalidades

- 💵 Conversão de valores entre diferentes moedas (ex: Real, Dólar, Euro).
- 🔄 Atualização dinâmica dos valores convertidos.
- 📱 Interface responsiva e fácil de usar.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilização e layout responsivo.
- **JavaScript (ES6+)**: Lógica de conversão e manipulação do DOM.

# 💸 ConvertMoney

   ConvertMoney is a simple and intuitive web application designed to perform real-time currency conversion.
   The project aims to provide a user-friendly interface that allows users to quickly and accurately convert amounts between different currencies.


   ## 🚀 Features

- 💵 Currency conversion between different currencies (e.g., Real, Dollar, Euro).
- 🔄 Dynamic updating of converted values.
- 📱 Responsive and user-friendly interface.

---

## 🛠️ Technologies Used

- **HTML5**: Page structure.
- **CSS3**: Styling and responsive layout.
- **JavaScript (ES6+)**: Conversion logic and DOM manipulation.
